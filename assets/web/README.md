# 🖋️ Pen-Pencil Ki Ladai (Pen Fight 3D Web)

> The unofficial sport of the last bench, now playable directly in your browser with real 3D Rapier physics and authentic school desk memories.

## 🎮 Play Live
- **Web App**: Hosted on Vercel with WebGL 3D physics.
- **Controls**:
  - **Desktop/PC**: Click and drag back behind your pen to set flick force and angle, then release to strike.
  - **Mobile**: Touch and drag back to aim and flick.

## 🛠️ Tech Stack
- **3D Graphics**: Three.js (WebGL)
- **Physics Engine**: Rapier 3D Rigid-Body Physics
- **Audio**: Howler.js Synthesized Classroom Sounds
- **Hosting**: Vercel Global Edge CDN
